# 「世界と話そう〜日本を伝えよう〜」申し込み管理システム 設計書

作成日：2026-07-10
対象LP：sekai-to-hanasou.html（https://musubu-kokoro-lp.vercel.app/sekai-to-hanasou.html）

## 目的

LPの各コースに申し込みリンクを設置し、申し込み〜振込案内〜入金管理〜当日出席リストまでを、
よしこさんが一人で運用できる仕組みにする。

## 全体構成（承認済み）

- 土台：Googleフォーム＋Googleスプレッドシート＋Google Apps Script（GAS）。すべて無料。
- 全コース（当日参加を含む）事前振込みで統一。
- 管理は ym.todayjapan@gmail.com のGoogleアカウントで行う。

## 全体の流れ

```
LPの各コースの「申し込む」ボタン
    ↓（コースが選択済みの状態でフォームが開く）
Googleフォーム送信
    ↓ 送信と同時に（onFormSubmitトリガー）
① スプレッドシート「申込リスト」に1行追加（フォーム標準機能）
② 申込者へ自動メール（お礼＋申込内容＋合計金額＋振込先＋振込期限）
③ よしこさんへ「新しいお申し込み」通知メール
    ↓
よしこさんが銀行明細を確認し、シートの「入金済み」列にチェック
    ↓（onEditトリガー）
④ 申込者へ「ご入金を確認しました」自動メール
⑤ 「当日出席リスト」タブに、その方の行が自動で追加される
```

## 1. LP（sekai-to-hanasou.html）の変更

- 3つのコースカード（親子セット20,000円／単独参加15,000円／当日参加5,000円）の
  それぞれに「このコースで申し込む」ボタンを追加する。
- ボタンのリンク先は同一のGoogleフォーム。URLの事前入力（prefill）パラメータで
  押したコースが選択済みの状態で開く。
- 「お申込みについて」セクションを「申込受付中」の内容に書き換える
  （申込ボタン＋振込みの流れの簡単な説明）。
- オープンチャットへの導線は残す。
- フォームURL確定までは href にプレースホルダ `FORM_URL_*` を使い、
  確定後に差し替えてデプロイする。

## 2. Googleフォームの項目

1. お名前（保護者の方）【必須・記述】
2. ふりがな【必須・記述】
3. メールアドレス【必須・記述・メール形式検証】
4. 電話番号【必須・記述】
5. 参加コース【必須・ラジオ】：親子セット（20,000円）／単独参加（15,000円）／当日参加（5,000円）
6. お子さんのお名前と年齢【任意・段落】（親子セットの方向け。例：はな（8歳）、たろう（5歳））
7. 自分の英語レベル【必須・ラジオ】：初級（これから楽しく始めたい）／中級（かんたんな会話ならできる）／上級（英語でのやりとりに慣れている）
8. カレンダー追加購入【必須・プルダウン】：追加なし／1冊（+1,500円）〜5冊（+7,500円）
9. フリーコメント（ご質問・メッセージなど何でもどうぞ）【任意・段落】

## 3. 自動メール（申し込み完了時）

- 送信元：ym.todayjapan@gmail.com（送信者名「Today Japan 増田美子」）
- 内容：
  - お申し込みのお礼（Today Japanのあたたかいトーン）
  - 申込内容の確認（コース、カレンダー追加冊数、英語レベル）
  - 合計金額の自動計算：コース料金＋カレンダー追加冊数×1,500円
  - 振込先：三井住友銀行 名古屋支店 普通口座（口座番号・名義はスクリプト内に設定。
    このリポジトリは公開のため、口座番号は Git 管理外の private/ 内ファイルにのみ記載する）
  - 振込期限：お申し込みから7日以内（申込日から+7日の日付「◯月◯日（曜）」を自動挿入）
  - 「振込手数料はご負担くださいますようお願い申し上げます」の一文
  - 問い合わせ先（ym.todayjapan@gmail.com）
- 同時に、よしこさん宛に「新しいお申し込みがありました」通知メール
  （お名前・コース・金額を記載）。

## 4. スプレッドシートの構成

### タブ1：申込リスト（フォームの回答シート）

フォーム標準の列（タイムスタンプ〜フリーコメント）の右に、管理用の列をスクリプトで追加：

| 列 | 内容 |
|---|---|
| 合計金額 | 送信時にGASが自動計算して記入 |
| 振込期限 | 申込日+7日をGASが自動記入 |
| 入金済み | チェックボックス（よしこさんが手動でチェック） |
| 入金日 | チェックした日をGASが自動記入 |
| 入金確認メール | 送信済みになるとGASが「送信済み」と記入（二重送信防止） |
| メモ | 自由記入 |

### タブ2：当日出席リスト

- 「入金済み」にチェックが入った時点で、GASがこのタブに1行追加する（追記方式。
  手動チェック列がずれないよう、数式による全面再生成はしない）。
- 列：お名前／ふりがな／コース／お子さんのお名前と年齢／英語レベル／カレンダー追加／出席チェック（当日用チェックボックス）
- チェックを誤って外した場合は、該当行を手動で削除する運用（手順書に明記）。

### タブ3：集計

- 数式（COUNTIF/SUMIF）でコース別の申込数・入金済み数・売上見込み・入金済み金額を表示。

## 5. 入金確認の自動メール（onEdit）

- 「入金済み」列にチェックが入ったら、その行の申込者へ
  「ご入金を確認しました。当日お会いできるのを楽しみにしています」という内容の自動メール。
- 「入金確認メール」列が「送信済み」の場合は再送しない。
- チェックを外しても取り消しメールは送らない（誤操作対策。出席リストの行だけ手動削除）。

## 6. セットアップ方法

- **setup.gs（セットアップスクリプト）を1本作成**。よしこさんが
  script.google.com に貼り付けて実行するだけで、以下が全部自動で出来上がる：
  1. Googleフォーム作成（上記項目すべて）
  2. 回答先スプレッドシート作成・タブ整備（管理列、出席リスト、集計）
  3. onFormSubmit／onEdit トリガーの設置
  4. コース別の事前入力済みフォームURL（3本）をログに出力
- 画面のどこを開いて何を押すかを一つずつ説明した、初めてでも迷わない手順書（Markdown）を同梱。
- フォームURL確定後、LPのプレースホルダを差し替えて Vercel にデプロイ。

## 7. エラー処理・制約

- GASからのGmail送信は無料アカウントで1日100通まで（今回の規模なら十分）。
- メール送信失敗時はスプレッドシートの「メモ」列に「メール送信エラー」と記録し、
  よしこさんに通知メールを送る。
- フォーム側でメール形式を検証し、宛先エラーを予防する。

## 8. テスト計画

1. セットアップスクリプトを実行し、フォーム・シート・トリガーが作成されることを確認。
2. テスト申し込み（各コース1件＋カレンダー追加あり）を送信し、
   自動メールの文面・金額計算・期限日付を確認。
3. 「入金済み」チェック → 入金確認メール送信・出席リスト追加を確認。
4. 二重チェック（チェック→外す→再チェック）で二重送信されないことを確認。
5. LPの3ボタンから、正しいコースが選択済みでフォームが開くことを確認。
