# 英語ドキドキ度チェック 設計

作成日: 2026-06-15
プロジェクト: Today Japan「世界と話そう、日本を伝えよう」プログラム告知

## 背景・目的
9月に名古屋でアジア大会が開催される。それに先駆け、夏休みの子どもが実際に外国人へ
話しかける体験プログラムを実施する。「日本人は英語を話せない」という思い込みを和らげ、
翻訳機ではなく自分の声で伝える体験を後押ししたい。

すでにオープンチャットを開始済み。その告知の入口として、気軽にできる診断ツールを作る。

## コンセプト
子どもが約1分でできる4択クイズ。「外国人に英語で話しかけるとき、自分はどんなタイプ？」
を診断し、自分の声で伝える一歩をやさしく後押しする。

## 全体の流れ
スタート画面 → 5問（各4択）→ 集計してタイプ判定 → 結果画面（タイプ＋応援メッセージ）
→「参加しやすい曜日」アンケートUI（送信は仮ボタン）→ もう一度ボタン

## 結果タイプ（4種）
- 🌏 ドキドキ探検家 … 緊張するけど挑戦したい / 「その勇気が宝物。一歩踏み出そう」
- ☀️ にこにこ勇者 … 笑顔で飛び込める / 「君の笑顔は世界共通の言葉」
- 📖 じっくり準備さん … 練習してから話したい / 「準備した言葉は必ず届く」
- 📱 翻訳機たより星人 … まだ機械に頼りがち / 「次は“自分の声”を試してみよう」

## 質問（5問・各4択）
1. 外国人の人を街で見かけたら？
2. 知らない英語の単語が出てきたら？
3. アジア大会で海外の選手に会えたら？
4. 英語で「ありがとう」を伝えるなら？
5. 自分の気持ちを伝えるとき、頼りにするのは？

各選択肢が4タイプのいずれかに対応してポイントを加算し、最多得点のタイプを表示する
（同点時は質問順で先に出たタイプを優先）。

## 結果後のアンケート（曜日）
「あなたの参加しやすい曜日を教えてね」というUI。月〜日のボタンを表示する。
**今回は見た目のみ実装**し、送信先（Googleフォーム等）は後で差し込めるよう仮ボタン（`#`）にする。

## 技術方針
- LP（index.html）と同じ配色・フォント・余白感の単一HTMLファイル `check.html`
- 素のJavaScriptのみ。画面はJSで表示切り替え（外部ライブラリなし）
- スマホ前提のレスポンシブ。タップしやすいボタンサイズ
- 1ファイル完結（CSS/JSはインライン）
